# HomeKeeper

Адаптивный Vue/Vite-каталог квартир и отелей. Проект создан на основе архитектуры сайта гостиницы «Рай», но использует отдельный бренд, новую контентную модель и нейтральные демонстрационные данные.

## Запуск

```bash
npm install
npm run fetch:images
npm run dev
```

Сборка для публикации:

```bash
npm run build
```

Фотографии загружаются локально из бесплатной коллекции Unsplash и используются по лицензии Unsplash. Данные объектов, цены, контакты и описания демонстрационные и не относятся к реальным объявлениям.
